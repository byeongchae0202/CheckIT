# CheckIT LCD 화면 동기화 규약

115200bps, ASCII, LF 종료. 웹앱과 이 버전의 checkit.ino를 함께 사용합니다.

## 화면 전송

```text
DISPLAY,<번호>,<상태>,<첫째 줄>,<둘째 줄>\n
ACK,DISPLAY,<번호>\n
```

- 번호: 1~10자리 십진수. Python은 1~4294967295 범위에서 순환합니다.
- 상태: RESET, SCAN, MISSING, READY, ERROR, EMPTY.
- 각 줄: 최대 16자. 준비물 이름에는 영문·숫자·공백·밑줄·하이픈을 사용합니다. 쉼표·개행은 허용하지 않습니다.
- READY는 반드시 `READY!,ALL CHECKED`, EMPTY는 반드시 `NO ITEMS,`를 보냅니다.
- 빈 둘째 줄을 포함해 필드 수를 정확히 유지합니다. 펌웨어 수신 버퍼는 80바이트이며 초과 입력은 ERR,OVERFLOW입니다.
- 모든 필드를 검증한 뒤 LED·서보 상태와 LCD 두 줄을 적용합니다. 오류 시 기존 상태와 화면을 유지하고 ERR,COMMAND를 반환합니다.

## 화면 선택

웹앱이 오늘 검사 대상 전체 목록에서 확인된 항목을 제거하고 목록 순서대로 앞의 2개 표시명을 전송합니다. Arduino가 전체 목록을 보관할 필요가 없으므로 준비물 개수는 LCD의 두 줄로 제한되지 않습니다. 오늘 제외한 항목은 전송 대상에서 빠집니다.

```text
DISPLAY,1,SCAN,BOTTLE,BOOK
DISPLAY,2,SCAN,BOOK,UMBRELLA
DISPLAY,3,SCAN,UMBRELLA,
DISPLAY,4,READY,READY!,ALL CHECKED
DISPLAY,5,EMPTY,NO ITEMS,
```

체크 해제·목록 수정·사용자 전환·날짜 변경·새 검사 때 최신 화면을 다시 계산합니다. 확인한 물건이 구역에서 사라지는 것만으로는 체크나 LCD를 되돌리지 않습니다.

## 연결과 수신 확인

- 실제 포트 연결 후 Uno 부팅을 위해 약 2초 대기합니다. 부팅 중 목록이 바뀌면 마지막 화면만 보관하고 대기 종료 후 전송합니다.
- 재연결 시 현재 화면과 상태를 자동 전송하며 검사 확인 결과를 초기화하지 않습니다.
- 이전 화면 번호의 ACK는 현재 화면의 수신 확인으로 인정하지 않습니다.
- 4초 응답 시간 초과 시 경고하며 ‘현재 상태 재전송’으로 같은 화면을 다시 보낼 수 있습니다.
- USB 오류·부분 전송 시 포트를 닫고 화면 수신 확인을 해제합니다. 최신 화면은 재연결을 위해 보관합니다.
- ACK는 명령 처리 확인입니다. LCD 미연결·주소 오류·USE_LCD 0에서도 ACK가 발생할 수 있으며 실제 표시 내용의 센서 확인이 아닙니다.
- LCD는 바뀐 줄만 16칸에 맞춰 덮어써 짧아진 이름 뒤의 잔상을 지웁니다.

## 기존 명령 호환

RESET, SCAN, MISSING,n(1~99), READY, ERROR와 기존 ACK 응답을 유지합니다. 하드웨어 버튼 이벤트는 START, CHECK입니다. 새 웹앱의 목록 전송은 DISPLAY를 사용하며, 구형 펌웨어는 DISPLAY를 거부하므로 최신 스케치를 한 번 업로드해야 합니다. 준비물 목록 변경마다 업로드할 필요는 없습니다.
